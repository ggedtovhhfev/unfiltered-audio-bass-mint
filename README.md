## Overview

Unfiltered Audio Bass-Mint adds depth and power to any low-end source through transient enhancement, sub-harmonic synthesis, and a precision low-frequency shelving EQ.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Unfiltered Audio Bass-Mint** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Sub Generator** | Synthesizes sub-octave harmonics to extend bass below speaker range |
| **Transient Punch** | Enhances attack transients of kick drums and bass instruments |
| **Low Shelf EQ** | Precision shelf EQ with adjustable frequency and Q for tonal control |
| **Saturation** | Tube-style saturation adds warmth and perceived loudness to bass signals |
